## Items can be sent even when the job never mentions a list
In Main, type what day is it today and press enter: Main answers with a date.
In Main, type how do you know that and press enter: Main answers in plain prose.
In Main, type /agent check Main's answers for accuracy and press enter: Main shows a line containing "Opened agent".
In Main, type can you access the windows host and press enter: Main answers.
View the agent pane and wait for it to finish: the agent has replied about Main's answer.
In the agent pane, press up with the input empty: a picker titled "Send which item to Main?" appears with at least one entry.
Press enter in the picker: the agent pane says "Sent #1 to Main".
View Main: its last line says "1 agent note".
